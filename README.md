# Duong Huy - Vo Lam Idle (ban dung lai)

Game Node.js thuan, khong dung thu vien ngoai. File chay: chay-game.js, cong mac dinh 8111, WebSocket /api/ws.

## Chay local

node chay-game.js 8111

## Tao tai khoan quan tri

node quan-tri.js them <ten> <mat-khau> --admin

## Railway

Start command: node chay-game.js $PORT --lan (Railway cap cong qua bien PORT, --lan de nghe 0.0.0.0). Gan volume 0.5 GB tai du-lieu/ de giu du lieu tai khoan/nhan vat.
